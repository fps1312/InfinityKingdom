# Gem Icons

Place the following gem icon images in this folder:

- `green-gem.png` - Green gem icon (for Basic Resource rewards)
- `red-gem.png` - Red gem icon (for Package rewards)  
- `purple-gem.png` - Purple gem icon (for Insights)

The images should be small icons (recommended size: 20x20px to 32x32px).

If the images are not found, the component will fall back to emoji icons (💚, ❤️, 💜).
